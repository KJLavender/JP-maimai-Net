隱私權說明

最後更新：2026-10-24

我們不收集你的資料

這個網站沒有帳號系統、沒有自己的伺服器，也不使用分析或廣告追蹤。你標記的「去過」「收藏」、篩選條件等， 只存在你自己瀏覽器的 localStorage 裡。

Google 同步（選用）

如果你按了「用 Google 帳號同步」：

  • 網站只會請求 drive.appdata 權限：只能讀寫網站自己在你 Google 雲端硬碟裡建立的一個隱藏檔案（maimai-sync.json）， 看不到、也不能修改你雲端硬碟裡的任何其他檔案。
  • 這個檔案只包含你標記為「去過」和「收藏」的機廳 ID 與標記時間。
  • 同步時，你的瀏覽器直接和 Google 連線；資料不會經過我們，我們也看不到。
  • Google 給的存取權杖只放在瀏覽器記憶體裡，關掉分頁或約一小時後就失效。
  • 按「停止同步」後這台裝置就不再同步（登入中的話也會一併撤銷授權）。要完全撤銷授權或刪除雲端上的檔案， 可到 Google 雲端硬碟 → 設定 → 管理應用程式，找到「全日本音遊機廳」選擇「刪除隱藏的應用程式資料」與「中斷與雲端硬碟的連結」。

第三方服務

地圖使用 OpenStreetMap 與 OpenRailwayMap 的圖磚、「搜尋此地」使用 OpenStreetMap Nominatim， 連線時你的瀏覽器會向這些服務送出一般的網頁請求（例如 IP 位址）。

Privacy

This site has no accounts, no server of its own, and no analytics or ad tracking. Arcades you mark as visited or favorite, and your filters, are stored only in your browser's localStorage.

If you turn on the optional Google sync, the site requests only the drive.appdata scope: it can read and write a single hidden file (maimai-sync.json) that it creates in your Google Drive's app data folder, and cannot see or change any of your other files. The file contains only the IDs of arcades you marked and when you marked them. Your browser talks to Google directly; the data never passes through us. The access token stays in browser memory and expires after about an hour. "Stop sync" turns sync off on that device (and revokes access if you are signed in); to fully revoke access or delete the hidden file, use Google Drive → Settings → Manage apps.

Map tiles come from OpenStreetMap and OpenRailwayMap and place search uses OpenStreetMap Nominatim; your browser sends ordinary web requests (such as your IP address) to them. Questions: GitHub Issues.
